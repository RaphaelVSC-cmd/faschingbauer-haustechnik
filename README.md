## 🛠️ Tech Stack & Features

- **Frontend:** Semantisches HTML5, Tailwind CSS, Vanilla JS
- **Motion & Scroll:** Lenis Smooth Scroll, GSAP 3.12.5, ScrollTrigger, SplitType
- **Design System:** Ethereal Oceanic & Industrial Thermal, Double-Bezel Architecture, 3D Tilt perspective, Aurora Gradient & Noise Overlay
- **Business Features:**
  - Palomar-Pattern Header mit einklappbarer Info-Leiste
  - Interaktiver 4-Gewerke Sanierungs- & Ersparnisrechner
  - Multi-Step Funnel Kontaktformular mit Formspree & Honeypot
  - Online-Terminbuchung UI-Dummy
  - WhatsApp Floating Widget mit Pulse-Effekt
  - DSGVO Consent Banner mit Google Maps 2-Klick Opt-In
  - Rechtssichere Double-Bezel Modals für Impressum (§ 5 TMG) & Datenschutz (DSGVO Art. 13)
  - Erweitertes Schema.org JSON-LD (HVACBusiness, FAQPage, OpeningHours)
